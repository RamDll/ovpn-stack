# install/ — установщик VLESS Reality + OpenVPN

Один запуск с домашнего ПК — от голого сервера (Debian 13 «trixie») с
root-паролем до рабочего VLESS Reality и/или OpenVPN с панелями,
TLS-сертификатом и файлом-сводкой.

Как оно устроено внутри, почему так и что ломалось на живых прогонах —
[`NOTES.md`](NOTES.md).

## Как запустить

На **домашней машине** (Linux / macOS / WSL2 — не на сервере):

```sh
git clone https://github.com/RamDll/ovpn-stack.git
cd ovpn-stack/install
./setup.sh
```

Нужен весь checkout — `setup.sh` дёргает соседние `bootstrap.sh`,
`install-vpn.sh` и `templates/` (не `wget` одного скрипта, как у
корневого `install.sh`). На сервере заранее ставить ничего не надо,
нужны только его IP и root-пароль.

**Сервер:** Debian 13, от 1 ГБ RAM. Диск: `--vless` хватит ~5 ГБ;
`--openvpn`/`--all` — от ~12 ГБ (локальная сборка образа `ovpn-admin`),
на 10 ГБ пройдёт впритык. При RAM < 2 ГБ добавляется swap 2 ГБ (+2.6 ГБ
диска). Кэш сборки (2–4 ГБ) скрипт чистит сам в конце.

**Требования к домашней машине:** `bash`, `openssh` (клиент ≥ 8.4),
`openssl`, `awk`/`sed`/`coreutils` — обычно уже есть. `qrencode` —
опционально (QR-код ключа в конце). Windows 10/11 — через WSL2
(`wsl --install`, дальше внутри Ubuntu как обычный Linux).

## Что делает скрипт

Шесть шагов, всё автоматически:

1. **Подготовка сервера** — обновление системы, часовой пояс,
   `unattended-upgrades` с ночным ребутом в 04:00, отдельный
   sudo-пользователь (не root).
2. **SSH-хардненинг** — отдельный ed25519-ключ под этот сервер, вход по
   паролю и под root отключается, порт меняется на случайный. Со
   страховкой: если новый доступ не подтвердить за 5 минут, всё
   откатывается само.
3. **Firewall** — свой nftables ruleset, политика `drop`, открыты только
   нужные порты.
4. **Сервисы** — Docker, 3x-ui (VLESS Reality), ovpn-admin (OpenVPN),
   nginx; TLS-сертификат Let's Encrypt **на IP** (домен не нужен).
5. **Первый VLESS-инбаунд** — Reality с локальной заглушкой как `dest`,
   готовая клиентская ссылка + подписка 3x-ui.
6. **Сводка** — все адреса, логины, пароли и ключ: печатается в терминал
   и сохраняется в `~/ovpn-stack-<ip>-summary.txt`.

Повторный запуск безопасен: ничего не пересоздаётся, имена/пути/пароли
берутся из `install/.state/<ip>/`, прогон продолжается с нужного места.

## Режимы

Спрашивается в начале, либо флагом: `--all` (по умолчанию в примерах),
`--vless` (только VLESS Reality), `--openvpn` (только OpenVPN). nginx и
TLS-сертификат нужны в любом режиме — панель есть всегда.

## Аргументы

```
./setup.sh [--vless|--openvpn|--all] [--ip <addr>] [--user <name>]
           [--ssh-port <port>] [--sni <domain>] [--staging] [--no-key-copy]
```

| Флаг | |
|---|---|
| `--vless` / `--openvpn` / `--all` | что ставить; без флага — меню в начале |
| `--ip <addr>` | IP сервера; без флага — спросит |
| `--user <name>` | имя sudo-пользователя на сервере; без флага дефолт — как на домашней машине (`whoami`), с подтверждением |
| `--ssh-port <port>` | SSH-порт после хардненинга; без флага — случайный 20000–60000 |
| `--sni <domain>` | домен для REALITY SNI; без флага спросит на «Шаге 5», Enter в промпте берёт случайный из встроенного пула |
| `--staging` | ACME staging Let's Encrypt — сертификат не доверенный браузером, но высокие лимиты: для повторных тест-прогонов установщика |
| `--no-key-copy` | не копировать приватный ключ в `~/.ssh` (останется только в `install/.state/<ip>/`) |

Секреты (root-пароль, пароль пользователя) флагом **не передаются** —
только интерактивный ввод. Полная справка — `./setup.sh --help`.

## Что спросит интерактивно

- **режим**, если не задан флагом;
- **IP сервера**, если не задан `--ip`;
- **имя sudo-пользователя** на сервере — Enter принимает дефолт (как на
  домашней машине). Это имя **нового** пользователя, не логин в
  существующий;
- **пароль этого пользователя** — Enter генерирует надёжный (нужен только
  для sudo на сервере);
- **root-пароль сервера** — тот, что прислал хостинг-провайдер при
  создании VPS; при первом подключении, скрытый ввод, вводится один раз
  (дальше только по ключу); неверный — переспросит до 3 раз;
- **домен для SNI** на «Шаге 5» — Enter берёт случайный из пула.

При повторном прогоне всё это берётся из
`install/.state/<ip>/state.env`, промпты пропускаются.

## После установки

**Сводка** (`~/ovpn-stack-<ip>-summary.txt`, `chmod 600`) содержит:
команду подключения по SSH, адреса и пароли панелей, первый VLESS-ключ
с QR-кодом, URL подписки (обычной и JSON), раскладку портов.

**SSH-ключ** копируется в `~/.ssh`: в `~/.ssh/id_ed25519`, если это имя
свободно (тогда подключение — просто `ssh -p <порт> <user>@<ip>`), иначе
в `~/.ssh/ovpn-stack-<ip>` (тогда в команде будет `-i`). `~/.ssh/config`
скрипт не трогает. После этого каталог `install/` можно удалять.

**Помнить:** IP-сертификат живёт ~6 суток, продление настроено
(systemd-таймер). Ночной ребут — 04:00. Смена IP сервера убьёт
сертификат. При полной потере SSH-доступа остаётся консоль в панели
управления сервером.
